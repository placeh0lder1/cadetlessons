# READ THIS IF YOU HAVE NO IDEA HOW TO USE GITHUB

- open the folders to the desired level
- inside each folder will be either a .pdf or .pptx version of a lesson
  - make sure to check for folders within folders
- click on the pdf version to preview the files
- click on the pptx/word/excel version to download the files
  - most pptx have animations/gifs that may not work on the web browser, so try to download the powerpoint app if possible, should be free with cadet/school account
  - you then click on "view raw" or "download raw file" to download the lesson as a pptx file
